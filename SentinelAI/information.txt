SentinelAI snapshot comparison prototype

The user manually submits text snapshots. The first submission establishes a
baseline without a model call. A changed snapshot produces a deterministic line
diff plus a model-written comparison through local Ollama. Identical submissions
reuse the saved result. SQLite retains snapshot revisions and brief history.

This version has no scheduled observation, automated feed, external actions,
authentication, model fine-tuning or production deployment. Briefs are generated
text for human review; their quotations and interpretations are not automatically
verified. The exact diff is the deterministic evidence. See the repository root
README.md and evidence/VERIFICATION.md for setup, checks and limits.
